# Django desencadenado

Siguiendo el [tutorial de Django 6.1](https://docs.djangoproject.com/es/6.1/intro/tutorial01/) paso a paso

## Puesta en marcha

creamos entorno virtual

```sh
python -m venv .venv
```

Instalamos dependencias

> Aqui se instalara la version especifica de Django que quedo anotada

```sh
pip install -r requirements.txt
```
